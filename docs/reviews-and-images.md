# 구매자 리뷰와 설명 이미지

- 상품 상세의 **리뷰 · 별점**에서 평균 별점, 별점 분포, 구매 확인 리뷰를 확인합니다. 최신순·별점순 정렬을 지원합니다.
- 서버 구매 기록이 있는 계정만 별점 1~5점과 후기(3,000자 이하)를 등록합니다. 작성자는 상품당 하나의 리뷰를 수정할 수 있습니다. 판매자는 본인 상품을 평가할 수 없습니다.
- 로그인한 사용자는 다른 사람의 리뷰를 신고할 수 있습니다. 사유와 상세 내용(1,000자 이하)을 기록하며 중복 신고는 거절합니다. 신고가 접수되어도 리뷰는 자동 삭제하지 않습니다.
- 신고는 `DATA_DIR`의 `report-*.bin`에 원본 리뷰 스냅샷과 함께 저장됩니다. 운영자는 서버에서 `node scripts/review-reports.mjs`로 확인할 수 있습니다. 별도의 웹 관리자 화면이나 알림 발송은 포함하지 않습니다.
- 새 상품 등록과 기존 본인 상품의 **설명 · 이미지 수정**에서 이미지 최대 4장을 첨부하거나 제거할 수 있습니다. PNG·JPEG·WebP, 원본 장당 5MB 이하를 지원하며 브라우저에서 크기를 줄입니다. 서버에서는 실제 이미지 형식을 확인하고 메타데이터를 제거한 WebP로 다시 저장합니다.
- 설명 이미지와 캡션은 구매 전에도 공개됩니다. 판매할 프롬프트 원문을 이미지에 넣지 마세요.
- 이미지, 리뷰, 신고는 기존 gzip 바이너리 저장 방식을 따릅니다. 압축은 암호화가 아니며 서버 파일 접근 권한이 있는 사람은 복원할 수 있습니다.

로컬 서버를 실행한 후 `node scripts/reviews-check.mjs`로 이미지 첨부·수정, 구매자 권한, 리뷰 수정, 신고, 입력 검증을 검사합니다. 테스트는 별도 로컬 데이터에만 임시 상품과 구매 기록을 만들고 종료 시 제거합니다.

리뷰 신고 흐름 참고: [Unity Asset Store Publisher portal](https://docs.unity.cn/Manual/AssetStoreAdmin.html).
